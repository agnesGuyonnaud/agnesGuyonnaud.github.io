Puissance 4

Puissance 4 est l'implémentation classique du jeu de société où deux joueurs s'affrontent pour aligner quatre jetons de leur couleur. Ce projet a été développé en Python avec une interface en ligne de commande.

Le jeu gère le plateau de jeu, les tours alternés, la détection de victoires (lignes, colonnes, diagonales), et empêche les mouvements invalides. Une version avec IA basique a également été ajoutée pour jouer contre l'ordinateur.

Ce projet m'a familiarisé avec les structures de données comme les listes 2D, les algorithmes de recherche, et la programmation modulaire.
